# Radix App

**Radix is a privacy-first, local AI assistant designed to match the capabilities of advanced web applications like Claude and ChatGPT, without the cloud-hosted overhead.** 

By running entirely on your local machine, Radix eliminates usage restrictions, mandatory sign-ups, and queue times. Equipped with native internet access and a secure virtual machine (VM) environment, Radix delivers powerful tool-use capabilities directly from your device through a clean Pygame GUI.

## Key Features

* **Complete Privacy:** Zero data tracking, telemetry, or external logging. Your interactions and code executions remain entirely on your device.
* **Resource Efficient:** Eliminates the massive server-side water and energy footprints associated with cloud-hosted data centers.
* **100% Local & Free:** No API usage limits, no premium tiers, and no subscription fees.
* **Advanced Tool Use:** Built-in web browsing and local VM execution allow the AI to handle complex, real-world tasks seamlessly.

> [!NOTE]
> All data stays local to your device. The sole exception is outbound web requests explicitly initiated by the AI during internet-connected tasks.

---

## How to Run

You can launch the application directly without needing the terminal, or run it with a single command:

* **No Terminal:** Simply double-click the `radix.py` file to launch the Pygame GUI.
* **Via Terminal:** 
  ```bash
  Radix_v1.py
  ```
